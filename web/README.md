# DocAI Web App

This is the unified Next.js app for DocAI at `docai.bizlegal-ai.com`.

## What is inside

- homepage with document-generation UI
- App Router contract-agent endpoints
- document upload, scan, and payment routes
- gated `/report/[scan_id]` experience

## Run locally

```bash
npm install
npm run build
```

Create `.env.local` from `.env.example` if you need to run the app outside the prepared workspace.
