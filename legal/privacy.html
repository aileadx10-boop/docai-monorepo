Accessibility

Accessibility Statement

Last Updated: [INSERT DATE]

RealDocs AI is committed to ensuring that our website is accessible to all users, including those with disabilities. We aim to comply with the Web Content Accessibility Guidelines (WCAG) 2.1, Level AA as our target standard.

Current Status

We are in the process of conducting a full accessibility audit of our website. This statement reflects our current efforts and known limitations.

Measures We Have Taken

  • Semantic HTML structure throughout the website
  • Keyboard navigation supported for all interactive elements
  • Sufficient color contrast ratios for body text (WCAG AA compliant)
  • Text alternatives provided for non-decorative visual elements
  • Forms include visible, programmatically associated labels
  • Font sizes expressed in relative units (rem) to support browser zoom
  • Focus indicators visible on all interactive elements

Known Limitations

  • Custom cursor: Our custom cursor effect is disabled on touch/mobile devices. On desktop, it may conflict with some screen reader pointer modes. Users can disable it via browser accessibility settings.
  • Decorative animations: Background grid and scroll animations are visual-only and contain no information. They do not affect screen reader output but may be distracting for some users. We plan to add a "reduce motion" preference that respects the OS-level prefers-reduced-motion setting.
  • PDF documents: Some downloadable templates may not yet be fully tagged for screen readers. We are working to ensure all documents include proper accessibility tags.

Technical Specifications

This website relies on the following technologies for conformance:

  • HTML5
  • CSS3
  • JavaScript (ECMAScript 2015+)

The website has been tested with the following browser/assistive technology combinations:

  • Chrome + NVDA (Windows)
  • Safari + VoiceOver (macOS)
  • Firefox + keyboard-only navigation
